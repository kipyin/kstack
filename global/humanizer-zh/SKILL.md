# humanizer-zh

**去AI味**: 扫出 AI 写作痕迹，改成具体、好念、像人写的句子；保留原意和语境语气。

模式目录与改写对照见 [PATTERNS.md](PATTERNS.md)（每条都要扫过输入）。上游：[Wikipedia:Signs of AI writing](https://en.wikipedia.org/wiki/Wikipedia:Signs_of_AI_writing)。

## Steps

### 1. 选 branch

done = 已判定走「意译」或「一般」；技术中文默认意译。

- **意译**（中文技术说明、PR/issue/设计笔记）：先走下方意译流程，再套 pattern 目录。语气冷静具体；不加个性或「灵魂」。
- **一般**（对外文案、叙事、随笔）：直接套原则 + pattern 目录。去痕之后，若原文需要声音，再补回观点、节奏和具体感受——无菌中立也是一种机器味。

### 2. 改写

done = 输入中每条命中的 AI 痕迹都已改掉；原意仍在；语气匹配 branch。

原则（改写时始终生效）：

1. **删填充** — 开场白、强调拐杖、聊天机器人套话一并去掉
2. **破公式** — 拆掉二元对比、戏剧分段、修辞铺垫、提纲式「挑战与展望」
3. **变节奏** — 句子长短交错；两项优于硬凑的三项；段落结尾有变化
4. **信读者** — 直接说事实；少软化、少辩解、少手把手
5. **删金句** — 听起来像可引用金句的，重写到平常话

意译流程（仅意译 branch，在 pattern 扫描前）：

1. 把当前中文（或草稿）逐句写成清楚的英文意思；技术概念用领域里真实英文词
2. 按英文意思用直白中文重写；逐词回译、英文语序硬套中文，都丢掉
3. 领域通用英文专名可保留；需解释时用人话说用途。优先同事口头会说的词（「写入数据库」优于「落库」）
4. 优先完整双音节词（若→如果，已→已经，未→没有）；标题和要点写完整短句、补回主语；路径、命令、代码标识符保持原样
5. 标点用逗号、冒号或短横；概念词用「」

通用写法，不为单次反馈追加临时禁词表。

对照 [PATTERNS.md](PATTERNS.md) 扫内容 / 语言 / 风格 / 交流 / 填充各类痕迹，命中即改。

### 3. 过清单并交付

done = 清单全过 + 已交出改写文本（可选附变更要点）。

交付前逐项打勾：

- [ ] 连续三个句子长度相同 → 打断其中一个
- [ ] 段末总是短金句 → 换结尾方式
- [ ] 破折号（—）在揭示前卖关子 → 改成逗号或句号
- [ ] 解释隐喻 → 删解释，留意象或改直说
- [ ] 「此外 / 然而 / 值得注意的是」 → 能删就删
- [ ] 硬凑的三段式 → 改成两项或四项，或收成一句
- [ ] 具体细节在，模糊夸大不在
- [ ] 大声读得顺

输出：改写后的全文；若有帮助，可附几条变更要点。

## 示例

**前：**
> 新的软件更新作为公司致力于创新的证明。此外，它提供了无缝、直观和强大的用户体验——确保用户能够高效地完成目标。这不仅仅是一次更新，而是我们思考生产力方式的革命。

**后：**
> 软件更新添加了批处理、键盘快捷键和离线模式。测试用户多数反馈任务完成得更快。
